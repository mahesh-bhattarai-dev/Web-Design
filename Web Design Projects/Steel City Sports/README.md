# Steel City Sports — Front-End Prototype

A Pittsburgh sports merchandise storefront concept built with HTML and CSS, with small JavaScript interactions. The pages explore a home page, team merchandise pages, a sample shopping-cart layout, and a customer-information form.

This is a **static front-end learning project**, not a live store. Product information and cart totals are written directly into the HTML.

## Project Goals

- Practice structuring multi-page HTML content.
- Style page elements with a shared CSS file.
- Link pages for different Pittsburgh sports teams.
- Explore product imagery, tables, navigation, and checkout-style layouts.

## Pages and Assets

- `index.html` — storefront landing page.
- `steelers.html`, `Pirates.html`, `penguins.html`, `riverhounds.html` — team-themed pages (check exact filename capitalization when opening or linking pages).
- `checkout.html` — a sample cart with hard-coded example items and totals.
- `payment.html` — a customer-information form for interface practice.
- `styles.css` — shared styles.
- `image/` and image files in the project folder — visual assets used by the pages.

## Run Locally

1. Download or clone the repository.
2. Open this folder.
3. Open `index.html` in a modern web browser.

No build step is currently documented for this static prototype. Some links or image paths may need adjustment depending on filename capitalization and the browser or operating system.

## Current Limitations

- The cart is static: quantities and totals are hard-coded in the page.
- The form does not process orders or make payments.
- There is no documented backend, inventory system, account system, or database connection.
- Navigation, image paths, and responsive behavior need a full review; some pages may have inconsistent link paths or markup.
- This project has not been presented as a production-ready or security-reviewed e-commerce system.

**Do not enter real personal, address, or payment information into this demo.** The form is for front-end practice only.
