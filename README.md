# Web Design & Development Practice

A learning repository for web development, front-end experiments, JavaScript exercises, Node.js examples, and SQL practice.

The goal of this repository is to keep examples organized by topic and make it easier to revisit concepts, test ideas, and build on earlier work. It is a collection of exercises and small projects—not a claim that every example is a finished, production-ready application.

## Repository Guide

| Folder | What's inside |
|---|---|
| [HTML](HTML/) | HTML examples, canvas experiments, animation, and page-building exercises |
| [CSS](CSS/) | Styling examples, layout, effects, and small interface experiments |
| [Javascript](Javascript/) | JavaScript fundamentals, control flow, arrays, DOM work, and browser API examples |
| [Bootstrap](Bootstrap/) | Bootstrap layout and grid exercises |
| [NodeJS](NodeJS/) | Small Node.js examples and server-side practice |
| [SQL](SQL/) | SQL table definitions, sample inserts, and SELECT-query exercises |
| [jquery](jquery/) | A small jQuery example |
| [Web Design Projects](Web%20Design%20Projects/) | Larger front-end practice folders, including Steel City Sports concepts |

## A Few Places to Start

- [JavaScript basics](Javascript/Basics/helloWorld.js) — a small first example.
- [SQL table creation](SQL/CREATE_table_song.sql) — an example relational table definition.
- [HTML animation example](HTML/Animation/animation.html) — a canvas-based basketball animation experiment.
- [Steel City Sports project folder](Web%20Design%20Projects/) — front-end practice pages and supporting assets.

These are examples from the repository, not a promise that every page has been recently tested in all browsers.

## How to Explore

Most HTML examples can be opened directly in a browser. JavaScript and SQL files are learning examples; how to run them depends on the file and any tools it uses. The Node.js examples may require Node.js to be installed.

Before running a project, review its files and any dependencies. Some examples may rely on external resources or require additional setup.

## Current Scope and Limitations

- This repository contains learning exercises and experiments with different levels of completeness.
- It is not currently presented as one unified application.
- Automated test coverage is not documented here.
- Some examples may need cleanup, setup notes, accessibility improvements, or browser testing before they are suitable for production use.

## Development Approach

I value practical experimentation, readable examples, and documentation that helps someone else understand the work. As projects mature, I aim to give the strongest ones their own focused README, clear setup steps, and screenshots or demonstrations where useful.
