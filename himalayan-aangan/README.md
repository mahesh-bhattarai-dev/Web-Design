# Himalayan Aangan

A responsive fictional Nepali and Indian restaurant website built as a portfolio demonstration.

## Included
- Nepali favorites: chicken momo, thukpa, dal bhat, Nepali thali, dhido with gundruk and achar, chatpate, masala chiya
- Existing menu items retained: chicken tikka masala, tandoori chicken, paneer chili, lamb curry, aloo gobi matar, vegetable samosa, onion pakora, garlic naan, dessert special, and more
- Menu category filters and an interactive cart
- Demo checkout only; no payment or real order submission

## Fictional business details
The restaurant name, address, phone number and email are fictional and are included only for portfolio use.

## Run
Open `index.html` in a browser. The page uses external Unsplash image URLs and Google Fonts, so an internet connection is needed for those visual assets.
